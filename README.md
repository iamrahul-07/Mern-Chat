# 💬 MERN Real-Time Chat Application

A full-stack real-time chat application built using the MERN stack. The application enables users to communicate instantly through Socket.IO with secure JWT authentication and image sharing powered by Cloudinary.

## 🚀 Live Demo

🔗 https://mern-chat-1-vxzp.onrender.com

---

## ✨ Features

### 👤 Authentication

- User Registration
- Secure Login
- JWT Authentication
- Protected Routes

### 💬 Real-Time Messaging

- Instant One-to-One Messaging
- Socket.IO Integration
- Live Message Updates

### 🖼 Media Sharing

- Upload Images
- Cloudinary Integration

### 🎨 User Interface

- Responsive Design
- Modern Chat Layout
- Clean User Experience

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/iamrahul-07/Mern-Chat.git
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
MONGO_URL=
JWT_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
